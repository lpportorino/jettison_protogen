# JonGuiDataFxModeDay

**Source:** `jon_shared_data_types.proto`

## Description

Represents selectable image processing presets for the day camera that optimize video quality for different environmental conditions. Includes DEFAULT plus six named presets (A-F) corresponding to scenarios like Daytime, Dusk, and Fog with distinct filter and processing algorithms.

## Values

| # | Name | Description |
|---|------|-------------|
| 0 | JON_GUI_DATA_FX_MODE_DAY_DEFAULT | Default processing |
| 1 | JON_GUI_DATA_FX_MODE_DAY_A | FX preset A |
| 2 | JON_GUI_DATA_FX_MODE_DAY_B | FX preset B |
| 3 | JON_GUI_DATA_FX_MODE_DAY_C | FX preset C |
| 4 | JON_GUI_DATA_FX_MODE_DAY_D | FX preset D |
| 5 | JON_GUI_DATA_FX_MODE_DAY_E | FX preset E |
| 6 | JON_GUI_DATA_FX_MODE_DAY_F | FX preset F |
