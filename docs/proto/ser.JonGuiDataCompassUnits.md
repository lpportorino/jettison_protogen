# JonGuiDataCompassUnits

**Source:** `jon_shared_data_types.proto`

## Description

Specifies the angular unit system for displaying compass bearing measurements. Supports four standard angle measurement units: degrees (0-360), mils (0-6400 military/tactical), gradians (0-400), and milliradians (0-2000).

## Values

| # | Name | Description |
|---|------|-------------|
| 0 | JON_GUI_DATA_COMPASS_UNITS_UNSPECIFIED | Unspecified/default value |
| 1 | JON_GUI_DATA_COMPASS_UNITS_DEGREES | Degrees (0-360) |
| 2 | JON_GUI_DATA_COMPASS_UNITS_MILS | NATO mils (0-6400) |
| 3 | JON_GUI_DATA_COMPASS_UNITS_GRAD | Gradians (0-400) |
| 4 | JON_GUI_DATA_COMPASS_UNITS_MRAD | Milliradians |
