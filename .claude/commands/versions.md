---
description: Show versions of tools in the Docker image
---

Display version information for all protobuf tools in the Docker container.

**Tools shown:**
- protoc (Protocol Buffers compiler)
- protoc-gen-go
- protoc-gen-validate
- nanopb
- ts-proto
- prost
- buf

**Usage:**
```
/versions
```

```bash
make versions 2>&1
```
