# JonGuiDataFxModeHeat

**Source:** `jon_shared_data_types.proto`

## Description

Defines available special effects (FX) modes for the thermal camera that control how the thermal image is processed and displayed. Includes DEFAULT plus six modes (A-F) representing different hardware-level or DSP-level image processing algorithms.

## Values

| # | Name | Description |
|---|------|-------------|
| 0 | JON_GUI_DATA_FX_MODE_HEAT_DEFAULT | Default processing |
| 1 | JON_GUI_DATA_FX_MODE_HEAT_A | FX preset A |
| 2 | JON_GUI_DATA_FX_MODE_HEAT_B | FX preset B |
| 3 | JON_GUI_DATA_FX_MODE_HEAT_C | FX preset C |
| 4 | JON_GUI_DATA_FX_MODE_HEAT_D | FX preset D |
| 5 | JON_GUI_DATA_FX_MODE_HEAT_E | FX preset E |
| 6 | JON_GUI_DATA_FX_MODE_HEAT_F | FX preset F |
